# 贵阳捉鸡麻将（单文件网页版）

一个**只有一个 HTML 文件**的贵阳捉鸡麻将：双击就能玩，不用安装、不联网，手机上也能玩。
内置三家电脑对手、完整算分（番型 / 豆 / 鸡）、音效与结算明细。

## 怎么玩

1. 双击 `index.html`（或发到手机上用浏览器打开）就能开始。
2. **点牌两次才打出**：第一次点 → 牌**弹起来**（预选）；再点同一张才真的打出去。
   中途点别的牌就改成那一张（旧的自动收回）——防误触。
3. **碰 / 杠 / 胡**：同时能做的动作会**全部**列在底部按钮里，点一下即可（如「胡 清大对｜碰｜过」）。
4. 想「添加到主屏 / 有图标 / 全屏」：把 `index.html`、`manifest.webmanifest`、`icon-192.png`、`icon-512.png`
   四个文件放同一目录（自己玩只拷 `index.html` 一个文件也够）。
5. **右上角是全屏按钮，右下角是 🔊 音效开关**（状态会记住）。

## 一局的总分怎么来

```
番数 = 牌型番（**取最高的一种**）
     + 自摸 +1 ／ 杠上花 +1
     × 抢杠胡 ×4 ／ 热炮 ×2
另有**独立**结算的几笔：豆（杠分）· 鸡分（常鸡/捉鸡/冲锋鸡/责任鸡）· 开局跟
```

- **番型取最高、不叠加**：清一色 + 大对子 → 取「清大对 15」，不是 10+5。
- 下面第 1~4 节讲**每一种胡牌怎么算**；第 5 节之后是**鸡牌**的完整口径（谁付给谁、归属、完整算例）。

## 番型与算分（每一种胡牌怎么算）

### 1. 牌型番表（**取最高**）

| 牌型 | 番 | 判定条件（怎么算出来的） |
|---|---|---|
| **天胡** | 33 | **庄家第一次摸牌**就自摸（此前没打过牌） |
| **地胡** | 23 | **闲家第一次摸牌**就自摸 |
| **天听** | 34 | **闲家**起手即听牌并按「报听」（报听按钮；之后摸什么打什么，不能换牌、不能碰杠） |
| **报听** | 17 | **庄家**起手即听牌并报听 |
| **清龙七对** | 20 | 七个对子 + 至少 1 组「四归一」（4 张相同算 2 个对子）+ **整副同一门** |
| **清七对** | 17 | 七个对子 + 整副同一门 |
| **大吊车** | 17 | **4 副露**（碰/杠）+ 单钓（手里只剩 1 张等对） |
| **清大对** | 15 | 全刻子（4 组刻子 + 1 对将）+ 整副同一门 |
| **龙七对** | 10 | 七个对子 + 至少 1 组四归一 |
| **清一色** | 10 | 顺子牌型 + 整副同一门 |
| **七对** | 7 | 七个对子（**不能有副露**） |
| **大对子** | 5 | 全刻子（4 组刻子 + 1 对将；**碰/杠出来的也算**） |
| **平胡** | 1 | 其余（顺子牌型） |

**「清」怎么判**：手牌 **+ 副露一起**看，全部同一门（万/条/筒）才算。

> 例：手里全是万、但碰的是筒 → **不算清**（是「大对子 5」，不是「清大对 15」）。

**特殊牌型说明**

- **天胡 / 地胡**：只在「本局第一次摸牌」那一刻成立（庄家叫天胡、闲家叫地胡）；第二次摸牌自摸不算。
  点炮胡**不算**天胡/地胡（它们都是自摸）。
- **报听 / 天听**：按下「报听」后不能再换牌，摸到什么打什么，也不能碰杠；
  牌型番按 17 / 34 与你的实际牌型**取最高**。
- **四归一**：4 张相同牌（如 4 张六筒）在七对里算 **2 个对子** —— 有它就叫「龙七对」。
- **大吊车**：4 副露之后手里只剩 1 张（单钓），任何一张配成对就胡，17 番。

### 2. 附加番（与牌型番一起算）

| 项 | 变化 | 触发条件 |
|---|---|---|
| **自摸** | **+1 番** | 自己摸到胡的那张（平胡 1 → 2 番） |
| **杠上花** | **+1 番** | 杠后**补摸**的那张牌正好自摸胡 |
| **抢杠胡** | **×4** | 别人**补杠**的那张牌正好被你胡 → 补杠者**一家包赔**（付全部分） |
| **热炮**（杠上炮） | **×2** | 点炮者**杠后打出的第一张牌**点了炮；同时他刚成的那个豆**不算**（撤销） |

### 3. 豆（杠分）—— 与番数**分开**算

| 杠法 | 豆 | 分值 | 谁付 |
|---|---|---|---|
| 暗杠 | **闷豆** | **2 分** | 其他三家各付 2（共 6） |
| 补杠 | **爬坡豆**（转弯豆） | **3 分** | 其他三家各付 3（共 9） |
| 明杠 | **点豆** | **1 分** | **放杠那一家**付 1 |
| 摸到杠牌没杠 | 憨包豆 | 0 分 | 不得分，但仍算「有豆」（可吃炮） |

- **前提：得豆必须听牌。** 本局结束时没听牌的人，豆**一分不算**。
- **热炮 / 抢杠胡**时该局的**鸡牌与豆分全部无效**（「全烧」）。

### 4. 通行证：豆决定你能不能吃炮

- **手里有豆（杠过）** → **平胡也能吃炮**（别人点炮你能胡）。
- **没有豆** → 只有**大对子（5 番）及以上**的牌型才能吃炮；**平胡/鸡胡只能自摸**。

### 5. 鸡分（总览，详细口径见后面各节）

| 鸡 | 分值 |
|---|---|
| 幺鸡（1条）/ 乌骨鸡（8筒） | **1 分/张**（金鸡时 2 分/张） |
| 本局**捉鸡牌**（翻牌点数 +1 的那张） | **1 分/张** |
| **冲锋鸡** | **2 分/家**（金鸡时 **4 分**） |
| **责任鸡** | 打出的幺鸡被叫牌家碰/杠走 → 打出者**多付 1 分** |

**金鸡是怎么来的**：胡牌时翻出牌墙第 1 张未摸的牌，**点数 +1** 就是本局的鸡。
翻到 **9条** → +1 → **1条**；翻到 **7筒** → +1 → **8筒**。
也就是「翻牌 +1 之后正好是幺鸡或 8筒」时，**这个牌种全场翻倍**：
听牌玩家手上的 1条（或 8筒）**按 2 分/张**算。

**黄庄（荒庄）**：豆、鸡**都不算分**；但要**查叫** —— 未听牌的人赔给每个听牌者「其听牌牌型的番值」。

**下一局谁坐庄**（首局由系统随机选庄）：

- 自摸 / 单家点炮 → **胡牌者接庄**
- **一炮双响**（正好 2 家胡）→ 由「上局庄家**逆时针第一个**胡牌者」坐庄
- **一炮多响**（3 家一起胡）→ **放炮者**坐庄
- 荒庄（黄庄）→ 庄家连庄

### 6. 目前**未实现**或与通用规则不同的地方（如实列出）

| 项 | 现状 |
|---|---|
| 一炮双响 / 一炮多响 | ✅ **已实现**：一张弃牌可被多家同时胡，放炮者按每家各自的番数**分别赔**；豆/鸡只算一次；定庄见 §1 上方说明 |
| 包鸡 | ❌ 未实现 —— 当前口径：未听牌家**打出的**鸡赔给听牌者（见 §4 第 3 行），**留着/亮出的**常鸡不赔 |
| 番型叠加 | ❌ **取最高**，不叠加 |
| 「杠 4 点」 | 杠**只走豆**（2 / 3 / 1），不再额外 +1 番 |

## ② 术语与分值（先认词，再算分）

| 术语 | 含义 |
|---|---|
| **叫牌家** | 本局**听牌（叫牌）的人 ∪ 胡牌的人**。胡牌的人必然叫过牌，所以合并成一个集合。 |
| **未叫家** | 既不胡、也没听牌的人。 |
| **翻牌** | 牌墙里**第 1 张未摸的牌**。有玩家胡牌且牌墙还有牌时才翻。 |
| **鸡牌（捉鸡牌）** | 翻牌**同花色点数 +1**（9 → 回到 1）。翻 5万 → **6万**是鸡；翻 9筒 → **1筒**是鸡。 |
| **常鸡** | 幺鸡（1条）、乌骨鸡（8筒）—— 它们**天生**是鸡，与翻牌无关。 |
| **金鸡** | 本局翻出的**鸡牌恰是幺鸡/8筒**时，该牌种全场升级：金幺鸡 / 金乌骨鸡。 |
| **冲锋鸡** | 本局**全局第一张**被打出的**幺鸡或乌骨鸡**（一局只有这一只，谁先打谁持有）。 |
| **责任鸡** | 打出的**幺鸡**被**叫牌家碰（或明杠）走**时，打出者要多付的那 1 分。**乌骨鸡不算**。 |

### 分值表（一张表定所有分值）

| 牌 | 平时 | **金**（本局鸡牌就是它自己） |
|---|---|---|
| 幺鸡（1条） | **1 分/张** | **2 分/张**（金幺鸡） |
| 乌骨鸡（8筒） | **1 分/张** | **2 分/张**（金乌骨鸡） |
| 本局鸡牌（第三门牌，例如 6万） | **1 分/张** | — |

> **铁律：一张牌只按一个身份算一次。** 翻到幺鸡时，"幺鸡"和"捉鸡牌"是同一张牌 ——
> 它是 2 分/张，**不是** 1+1=2 之外再叠加。

## ③ 谁付给谁（收付骨架，三句话）

```
① 鸡分        未叫家 ──→ 叫牌家        每个未叫家 × 每个叫牌家，各付 v 分
② 冲锋鸡      看**持有者**身份：
                持有者是叫牌家 → **其他三家**各付给他（**含赢家** —— 赢家该付的照付）
                持有者是未叫家 → 他给每个叫牌家各付
                这张牌被**叫牌家**碰/杠走 → 持有者换成那个人（**责任转移**）
③ 责任鸡      打出者 ──→ 碰走那张牌的人   固定 1 分
                （前提：碰走者叫牌、打出者未叫；这副露本身按碰 3 / 杠 4 张算）
```

三个必然结果，可以当检查用：

- **听牌家之间互不赔**，**未叫家之间互不赔** —— 鸡分只有一个方向。
- **四家都听牌** → 没有未叫家 → 鸡分不转移（但冲锋鸡照算：它是**其他三家各付**，与听牌/胡牌无关）。
- **全场无人听牌** → 鸡分不结算。
- 任何一局，四家的收付**加起来必为 0**（钱只是在挪，不会凭空产生）。

## ④ 鸡的归属：四种情形（最容易搞错，单独成节）

按"这张鸡在谁那儿、处于什么状态"分四种，**两种口径**：

| # | 这张鸡在哪 | 归谁收 | 依据 |
|---|---|---|---|
| 1 | **叫牌家**自己手里 / 副露 | 他自己 | — |
| 2 | **叫牌家**的牌河（自己打出的） | 他自己 | — |
| 3 | **未叫家**的牌河（打出的） | **每一个叫牌家**（各一份） | 规则①前半 + "特别地" |
| 4 | **未叫家**手里 / 副露（留着的） | 常鸡 → **谁都不收**；<br>捉鸡牌 → **每一个叫牌家** | 规则①后半（常鸡）<br>规则②⑤（捉鸡牌：无论在手还是已打出） |

**口诀**：**"打出去的白送；留着的——常鸡不送、捉鸡照送。"**

两条必须记住的细节：

- **副露算"留着的"**（碰/杠亮出来的牌还在自己门前），只有进牌河才算"打出的"。
- **牌随人走**：某张幺鸡被打出、又被碰走，它就从原主牌河**转移到碰牌者的副露**里 →
  之后算**碰牌者**的（他不是叫牌家就不算；他是叫牌家就按 3 张算）。

## ⑤ 五条规则逐条

### 5-0 前置：听牌 / 未听牌怎么判

在**结算那一刻**逐家判，两条同时成立才算听牌：

1. **手牌张数是 3n+1**（13 / 10 / 7 / 4 / 1 张 —— "刚打完牌、在等摸牌"的形态）。
   14 张（刚摸完没打）、11 张（碰完没摸）这类 3n+2 的形态**一律判为未听牌**。
2. 存在**至少一张牌**，补进来能成"4 面子 + 1 将"或"七对"。
   - 用**自摸口径**判：**不受"豆"限制** —— 没杠也算听牌（豆只管"能不能吃别人的炮"）。
   - **副露一起参与**判定（碰/杠出来的面子照算）。

> **胡牌者一律算叫牌家。**

### 5-1 归属判定（弃牌里的鸡归谁）

- **弃牌者是听牌家** → 这枚鸡**归他自己**收。
- **弃牌者是未听牌家** → 这枚鸡**改判给每一个听牌家**（各一份）；
  而且**打出者自己**也在"未听牌家"里，所以**他也要赔**这一份。
- 同一家的"手里的 vs 打出的"在未听牌时结果相反（见 §4 第 4 行与口诀）。

### 5-2 翻牌鸡 / 捉鸡（一张牌的两种叫法）

- **翻牌时机**：有玩家胡牌、且牌墙还有牌 → 翻第 1 张未摸的牌，其 **+1 顺位**为本局鸡牌。
  牌墙已空（荒庄）→ 不翻牌，本局只有常鸡。
- **计数范围**：**所有玩家**的牌，**包括已打出的**。
- 这一张牌就是"捉鸡"：**胡牌后本该摸的那张牌的下一张**，与上面翻出来的是同一张，
  两个名字指的是同一件事，不是两笔分。

### 5-3 冲锋鸡

- **身份**：本局**全局第一张**被打出的**幺鸡或乌骨鸡** —— 一局只有这一只，**谁先打谁持有**。
- **分值**：**2 分**；本局翻到**金鸡**（鸡牌 = 幺鸡）→ **4 分**。
- **责任转移**：这张牌被**叫牌家**（听牌或胡牌）**碰/杠走** → 持有者换成**碰走的那个人**；
  碰走者自己**没叫牌** → 不转移，仍归原打出者。
  > 用**结算那一刻**的听牌状态判断（碰的当时他还没听、后来听了，也算他叫牌）。
- **收付**：看**持有者**是不是叫牌家：

| 持有者 | 收付 |
|---|---|
| 叫牌家 | **其他三家各付 2（4）分**给他 —— **含赢家** |
| 未叫家 | 他**给每个叫牌家各付 2（4）分** |
| 全场无人叫牌 | 不结算 |

> ⚠️ 这里是"**其他三家**"，与对方**听不听、胡不胡无关** ——
> 也就是说 **赢家该付的照付**（他只在这笔上净额可能是负的）。

### 5-4 责任鸡

- **身份**：打出的**幺鸡**被**碰或明杠**走（**乌骨鸡不参与责任鸡**；本局捉鸡牌在打牌时还没翻出来，也不算）。
- **收付**：那副露按 **碰 3 张 / 杠 4 张**计入碰走者的鸡分（这就是"**其它家给 3**"），
  而打出这张牌的人**多付 1 分**（"**打出的给 4**"）—— 多出的这 1 分付给碰走者。
- **两个前提**（都在结算时判）：

| 前提 | 不满足时会怎样 |
|---|---|
| 碰走者必须**叫牌** | 那副露的鸡不算（未叫家留着的常鸡本来就不计）→ **整条不结算** |
| 打出者必须**未叫** | 他与碰走者同为叫牌家 → 鸡分互不赔 → 不产生收付（明细里写明） |

- **边界**：与冲锋鸡**同时成立、互不抵消**；有多张鸡被碰走就**逐条累加**（`G.respChickens[]`）。


```
### 5-5 分数怎么累加

一局总分 = 牌型番（**取最高**；自摸 +1、杠上花 +1、抢杠 ×4、热炮 ×2）
         + 豆   （闷豆 2 / 爬坡豆 3 / 点豆 1；**得豆必须听牌**）
         + 鸡分 （常鸡 + 捉鸡，按 §3 §4）
         + 冲锋鸡 + 责任鸡
         + 开局跟（4 分：庄家首张 + 三家第一张都跟打同一牌 → 三家各从庄家收 4）
```
以上几笔**独立相加**，互不折算；每一笔都是零和（四家合计 = 0）。

### 5-6 边界情形

| 情形 | 处理 |
|---|---|
| 四家都听牌 | 鸡分不转移（没有未叫家）；冲锋鸡照算 |
| 全场无人听牌 | 鸡分不结算 |
| 荒庄（黄庄） | **豆、鸡都不算分** —— 只把各家的鸡牌统计列出来看 |
| 牌墙已空 | 不翻牌 → 本局没有捉鸡牌，只有常鸡 |

## ⑥ 完整算例（把上面全部规则串一遍）

**牌面**：你（0）自摸胡牌；翻牌是 **5万** → 本局**鸡牌 = 6万**（非金鸡，每张 1 分）。

| 家 | 状态 | 手里的鸡（留） | 牌河里的鸡（打） |
|---|---|---|---|
| **你**（0） | 胡牌 → **叫牌家** | 无 | 幺鸡×1、6万×1 |
| 下家（1） | 未听牌 → **未叫家** | 幺鸡×2、8筒×1 | 幺鸡×1、6万×1 |
| 对家（2） | 未听牌 → **未叫家** | 幺鸡×3（**碰来的副露**） | 无 |
| 上家（3） | 未听牌 → **未叫家** | 6万×1（**捉鸡牌**） | 无 |

另外两笔特殊鸡：**冲锋鸡** = 下家打出的第一张幺鸡（主人是未叫家）；
**责任鸡** = 那张幺鸡被对家碰走。

### 第一步：算"你"从**每个未叫家**能收多少

| 来源 | 明细 | 分数 |
|---|---|---|
| 你自己（叫牌家） | 牌河 幺鸡×1（1）+ 6万×1（1） | **2** |
| 下家打出的 | 幺鸡×1（1）+ 6万×1（1） | **2** |
| 下家留着的 | 幺鸡×2、8筒×1 → 常鸡且未叫、又是留着的 → **不算** | 0 |
| 对家留着的 | 幺鸡×3（碰来的）→ 常鸡且未叫 → **不算** | 0 |
| 对家打出的 | 无 | 0 |
| 上家留着的 | **6万 = 本局捉鸡牌** → 宽口径，**留着的也要赔** | **1** |
| 上家打出的 | 无 | 0 |
| **每个未叫家应付** | 2+2+0+0+0+1+0 | **5 分** |

### 第二步：转账

| 项目 | 你 | 下家 | 对家 | 上家 |
|---|---|---|---|---|
| 鸡分：三家各付 5 给你（**+15 / −5 / −5 / −5**） | +15 | −5 | −5 | −5 |
| 冲锋鸡：持有者"下家"是未叫家 → 给每个叫牌家（你）各付 2 | +2 | −2 | 0 | 0 |
| 责任鸡：下家的幺鸡被**对家**碰走，但对家本身**未叫牌** → 那副露的鸡不算，**本条不结算** | 0 | 0 | 0 | 0 |
| **鸡分小计** | **+17** | **−7** | **−5** | **−5** |
| 牌型番：自摸清大对 = 15 + 自摸 1 = **16**，三家各付 | +48 | −16 | −16 | −16 |
| **一局合计** | **+65** | **−23** | **−21** | **−21** |

**验算**：65 − 23 − 21 − 21 = **0** ✓（钱只在四家之间挪）

> 也可以只记鸡分那一行来核对：17 − 7 − 5 − 5 = 0 ✓

### 变体：如果碰走那张幺鸡的"对家"**是叫牌家**

同一个牌面，只把**对家改成听牌**，就能一次看到"责任转移"和"给 3 / 给 4"：

| 发生什么 | 结果 |
|---|---|
| 那副露的 3 张幺鸡 | 对家叫牌 → 算他"留"的鸡 → **每个未叫家（下家、上家）各付 3** |
| 责任鸡 | 打出的那张来自**下家** → 下家**多付 1** → **下家付 4、上家付 3**（就是"其它家给 3 鸡、打出的给 4 鸡"） |
| 冲锋鸡**责任转移** | 持有者从"下家"换成"对家" → 对家向**其他三家**各收 2（**含赢家**）|

## ⑦ 结算界面怎么读

引擎会逐家输出一行，格式固定：

```
翻（捉）鸡牌：6万                                  ← 本局的鸡牌（金鸡时后面标「（金幺鸡 ×2）」）
你［叫牌］留 幺鸡(1条)×2 乌骨鸡(8筒)×4（6分）        ← 手里+副露（"留"），括号里是他自己的鸡分
下家［未叫］留 幺鸡(1条)×1 ｜ 打 幺鸡(1条)×1（4分）    ← 「留」与「打」分开列，一眼看出哪张作数
对家［未叫］打 6万×1（1分）
上家［未叫］无鸡
鸡分：你 每个未叫家收 8 分 × 3 家                    ← 收付方向与金额
冲锋鸡：下家 打出的第一张幺鸡(1条)（未叫）→ 给每个叫牌家各付 2 分 × 1 家
责任鸡：下家 的第一张幺鸡(1条) 被 对家 碰走 → 下家 额外多付 1 分
```

读的时候只要盯三处：

1. **［叫牌］/［未叫］** —— 决定他是收钱还是赔钱；
2. **「留」/「打」** —— 未叫家的"留"多数不作数，"打"一定作数；
   **例外**：鸡牌是捉鸡牌时，"留"也作数（明细里照样列出来，方便核对）。
3. **"×N 家"** —— 收付是"每个未叫家各付"，所以一家收的总数会乘上未叫家数。
